# Skill de desenvolvimento Front-end

## Objetivo

Padronizar a criação e manutenção das interfaces do sistema SIGAD, garantindo organização, responsividade e facilidade de manutenção.

## HTML

- Utilizar HTML5 semântico.
- Organizar corretamente os elementos das páginas.
- Reutilizar os templates base existentes.
- Utilizar corretamente os templates do Django.
- Manter formulários acessíveis e organizados.

## CSS

- Manter os estilos organizados nos arquivos CSS correspondentes.
- Evitar duplicação de regras.
- Preservar a identidade visual do SIGAD.
- Utilizar layouts responsivos.
- Evitar alterações globais que possam prejudicar outras páginas.
- Testar as alterações em diferentes tamanhos de tela.

## JavaScript e jQuery

- Manter os scripts organizados.
- Evitar duplicação de eventos e funções.
- Utilizar seletores adequados.
- Verificar se os elementos existem antes de manipulá-los.
- Garantir que os eventos funcionem corretamente.
- Evitar conflitos entre scripts.

## Bootstrap e plugins

- Reutilizar os recursos do Bootstrap já instalados.
- Utilizar plugins jQuery conforme suas finalidades.
- Evitar carregar bibliotecas repetidamente.
- Verificar a compatibilidade entre os plugins utilizados.

## Responsividade

- Garantir que as páginas funcionem em computadores, tablets e celulares.
- Utilizar media queries quando necessário.
- Evitar elementos que ultrapassem os limites da tela.
- Testar menus, tabelas, formulários e botões em telas menores.

## Cuidados com o projeto

- Analisar os arquivos antes de modificá-los.
- Preservar funcionalidades e estilos existentes.
- Não alterar a estrutura visual de páginas sem necessidade.
- Não substituir arquivos completos sem considerar o conteúdo atual.
- Manter a compatibilidade com os templates existentes.

## Validação

Após realizar alterações:

1. Verificar o HTML.
2. Conferir os estilos CSS.
3. Testar os eventos JavaScript e jQuery.
4. Verificar a responsividade.
5. Testar a página no navegador.
6. Confirmar que outras páginas continuam funcionando.
